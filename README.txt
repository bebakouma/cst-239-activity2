# CST-239 Activity 2: Inheritance

This project contains all four parts of Activity 2 for CST-239: Object-Oriented Programming at Grand Canyon University.

## Contents
- Part 1: Super Hero Battle (Inheritance & Polymorphism)
- Part 2: Weapons, Bombs, and Guns (Abstraction, Overloading, Overriding)
- Part 3: Comparing Person Objects (equals & toString)
- Part 4: Debugging Practice (Eclipse Debugger)
